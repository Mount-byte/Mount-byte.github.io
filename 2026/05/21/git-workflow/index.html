分支生命周期

  1. 创建分支：从主分支创建
  2. 开发工作：在分支上进行开发
  3. 代码审查：提交Pull Request
  4. 合并分支：通过审查后合并
  5. 删除分支：合并后删除

类型 说明

test 测试更新

Pull Request流程

  1. 创建PR：提交功能分支
  2. 代码审查：团队成员review
  3. 自动化测试：CI/CD自动运行
  4. 反馈修改：根据反馈更新代码
  5. 合并PR：审查通过后合并

代码审查要点

  • 代码质量
  • 逻辑正确性
  • 安全性
  • 性能优化
  • 代码风格一致性
