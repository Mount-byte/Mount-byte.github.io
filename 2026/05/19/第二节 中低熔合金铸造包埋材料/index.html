《第六章 铸造包埋材料》教学设计

第二节 中低熔合金铸造包埋材料

一、授课方法

  1. 逻辑推演法：从石膏的凝固本性出发，推演其固化膨胀机制；从石膏遇水继续反应的特性，推演吸水膨胀的本质；从二氧化硅与石膏受热的物理化学变化，推演热膨胀与冷却收缩的叠加结果。

  2. 图表解析法：充分利用教材中的图6-2（固化与吸水膨胀）、图6-3/6-4（二氧化硅晶型转变）、图6-6（加热与冷却曲线），将抽象的体积变化转化为直观的视觉认知。

  3. 口诀提炼法：将临床获得吸水膨胀的3种方法及温度控制红线提炼为简练口诀，降低记忆负担。

  4. 反向案例警示法：通过展示石膏高温分解产生二氧化硫腐蚀金属铸件的真实案例，强化温度控制红线意识。

二、教学目标

知识目标

  • 掌握石膏类包埋材料的三种膨胀形式（固化膨胀、吸水膨胀、热膨胀）及其机制。
  • 掌握临床获得吸水膨胀的三种操作方法。
  • 掌握石膏类包埋材料的加热温度限制（700℃以下）及原因。
  • 熟悉水粉比例对固化时间、膨胀率、机械强度的影响。
  • 了解一次包埋法与二次包埋法的适用范围及操作要点。

能力目标

  • 能够根据铸件的精度要求，合理选择并调节包埋材料的膨胀率。
  • 能够在临床操作中严格控制烘烤焙烧温度，避免铸件污染和变形。

素质目标

  • 培养严谨求实的工作作风，理解”差之毫厘，谬以千里”的工艺特性，树立规范操作的职业素养。

三、教学重点

  1. 石膏类包埋材料的三种膨胀形式及调控机制。
  2. 临床获得吸水膨胀的三种具体方法。
  3. 水粉比例对各性能（固化时间、膨胀率、强度）的影响规律。
  4. 铸造石膏类包埋材料的加热温度红线（<700℃）及其原因。

四、突出重点的方法

1. 机制拆解法（突破膨胀机制）

将”吸水膨胀”拆解为逻辑链——石膏反应需耗水 → 加水补充反应消耗 → 针状结晶继续生长推挤 → 膨胀加剧（实质是固化膨胀的延续），变死记为理解。

2. 口诀归纳法（突破吸水膨胀方法）

将三种方法提炼为”贴湿纸、泡温水、注水枪“，辅以动作比划，形成肌肉记忆。

3. 变量关系矩阵法（突破水粉比影响）

在黑板上画出”水粉比↑”的箭头，依次推导出”固化时间↑、膨胀率↓、强度↓”的反向关系矩阵，一目了然。

4. 红线警示法（突破温度限制）

用红色粉笔在板书上重重画下”700℃”红线，并展示因超温导致铸件表面变色腐蚀的废品图片，产生视觉与逻辑的双重冲击。

五、教学难点

  1. 二氧化硅的晶型转变（α型与β型）对热膨胀的影响。
  2. 包埋材料加热与冷却过程中的体积变化规律（为何冷却后表现为不可逆的净收缩）。

六、难点突出方法

1. “弹簧与干泥”比喻法（突破冷却收缩难点）

  • 将二氧化硅比作”弹簧“，受热膨胀，冷却后可逆恢复原长。
  • 将石膏比作”湿泥巴“，受热后水分蒸发变成干瘪的硬泥（无水石膏），冷却后无法吸水复原，体积变小。
  • 叠加结果：弹簧缩回原位 + 干泥巴变瘪 = 整体尺寸比加热前缩小（不可逆收缩）。

2. 动态曲线绘制法（突破晶型转变难点）

在黑板上临摹图6-3和图6-6，用不同颜色粉笔标出石英（573℃）、方石英（220℃）的体积突变平台，以及图6-6中加热线与冷却线的分离点，动态展示温度节点上的体积剧变。
